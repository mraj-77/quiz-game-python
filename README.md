# Quiz Game 🧠

A simple console-based Quiz Game built with Python, where users answer questions and get their final score at the end.

## Features
- ❓ Multiple questions stored using list of dictionaries
- ✅ Checks user answers (case-insensitive matching)
- 📊 Tracks score for correct answers
- 🏆 Displays final score at the end

## How to Run
```bash
python quiz_game.py
```

## Concepts Used
- List of Dictionaries (to store questions and answers)
- Loops (to iterate through questions)
- String methods (`.lower()` for case-insensitive comparison)
- Conditional statements (if-else)
- Variables (score tracking)

## Sample Usage
Capital of India kya hai?
Your answer: delhi
Correct! ✅

Capital of Bihar kya hai?
Your answer: mumbai
